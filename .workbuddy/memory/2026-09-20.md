## 板块② 联网核实的事实（2026-09-20 查，写进文档时附来源）

### GitHub Pages 官方限制（github/docs「about-github-pages」）
- 源仓库建议 ≤1 GB；发布站点 ≤1 GB（均为**软限制**，超了不是账单，是限流）
- 带宽软限制 **100 GB/月**；构建软限制 **10 次/小时**（走自定义 Actions 工作流不受此限）
- 单次部署超时 **10 分钟**（硬限制）
- Git 层面单文件超 **100 MB** 会被拦
- **免费仅限公开仓库**；私有仓库需 GitHub Pro（$4/月）
- **不支持服务端代码**（无 API、无 SSR、无函数）

### 页面体积 × 加载耗时（多来源）
- 4G（实测约 20 Mbps）：3 MB ≈ 1.2 s 纯传输；5 MB ≈ 4–6 s
- **真实耗时通常是纯传输的 2–3 倍**（DNS、TCP/TLS 握手、渲染开销）
- 3 秒法则：加载 >3 s 有 53% 用户离开
- 图片通常占页面体积 **50–70%**；WebP/AVIF 可省 **30–50%** 图片字节
- 结论：本项目 5 MB 上限在 4G 下约 4–6 s，**属可接受但需压缩**；这也是 PRD 第 7 节「单张 ≤1.0 MB」的合理性依据
