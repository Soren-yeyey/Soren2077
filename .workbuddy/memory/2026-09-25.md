## 踩坑

- ⚠️ **Git Bash 里 `python -c "…"` 的双引号会吞反斜杠**：`\s` 被 MSYS 路径转换吃成 `/s`，正则**静默失效** → 打印出"匹配到 0 处 font-size"这类结论**全是错的**，差点据此误判改动失败。改用不含反斜杠的写法（`[;]` / `[*]` 代替 `\;` / `\*`）或把脚本用单引号包裹。
- `git ls-remote` 在本轮当场报 `Recv failure: Connection was reset` —— 代理对 `github.com` 又抽了一次，推送前先探连通性。
- 无头量测时 `document.querySelector("[data-id=washer]")` **不加引号**也生效（属性值无空格时合法），但沿用带引号的写法更稳。
