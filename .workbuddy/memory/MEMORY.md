- 项目根：`D:\workbuddy`，AGENTS.md 保存用户本人的协作规则（2026-09-16 写入）
- 协作模式：**清单驱动 + 单步推进**。用户每天发「今日任务清单」，清单即当天唯一任务范围
- 收到清单后只输出执行计划并停下，等确认；之后**一次只做一个步骤**，做完报告三件事（做了什么 / 改了哪些文件 / 怎么验证）后停下
- 用户必须回复「进入下一板块」才允许继续；这四个字只对当前步骤有效
- 需要人工操作的事（注册、点按钮、装软件、截图）不代做、不假装完成，只给操作指引后停下
- 需要拍板的事（方案/命名/风格）列选项和代价给用户选，不自己决定
- 生成内容（文档/文件/代码）必须等用户明确说"做"再动手
- 验证必须可亲眼确认（页面/文件/命令输出），不接受口头结论
- Git：授权代提交推送，但提交前先列改动文件清单（含属于哪天的任务）等确认；commit 格式 `Day X｜一句话说明`；一天全部做完并核对后才提交，禁止 `git reset --hard` 和强推，撤销用 `git revert`
- 用户说「今天做完了」→ 逐条对照完成标准输出表格（完成标准 / 状态 / 证据），不得模糊处理
- 密钥、`.env`、连接串永不进代码/提交
